# capacitor-native-ocr

On-device OCR for Capacitor: Apple Vision on iOS, ML Kit on Android, with word-level boxes

## Install

To use npm

```bash
npm install capacitor-native-ocr
````

To use yarn

```bash
yarn add capacitor-native-ocr
```

Sync native files

```bash
npx cap sync
```
